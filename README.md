# 🧳 旅行英会話マスター

旅行で困らない英会話を **Lv.1〜100** のステップで身につけるブラウザアプリ。
スマホでもPCでも、ブラウザだけで動く完全静的サイトです。

**🎮 公開URL: https://wamoto1022.github.io/english-app/**

---

## ✨ 特徴

- **5ステージ・全25シュチュエーション** で会話の長さが段階的に伸びる
- **Lv.1 = 6〜8往復の短い会話** から **Lv.100 = 30往復超の超長文会話** まで
- ブラウザの音声合成 (TTS) で英語を自動再生・速度調整可能
- 日本語訳は基本非表示・タップで一時表示できる
- 進捗は端末内 (localStorage) に自動保存
- AIや外部APIは使っていない (静的データ駆動・通信不要)

## 🎯 ゴール

英検3級レベルの方が「レストラン・飛行機・道案内・友達雑談」など旅行で出会う英会話を、相手の返答まで含めて理解・応答できるようになる。

## 📚 ステージ構成

| Stage | レベル | 難易度 | 1会話あたり |
|---|---|---|---|
| 🌱 Beginner | Lv 1〜20 | 入門 | 6〜8往復 |
| 🌿 Elementary | Lv 21〜40 | 初級 | 10〜12往復 |
| 🌳 Intermediate | Lv 41〜60 | 中級 | 14〜16往復 |
| 🏔️ Advanced | Lv 61〜80 | 上級 | 22〜26往復 |
| 👑 Master | Lv 81〜100 | マスター | 30〜34往復 |

各ステージは前ステージの全シュチュエーションを最低1星クリアで解放。

## 📖 使い方 (おすすめの学習フロー)

1. **🔊 Play で聞く** — 意味を追わず音だけ聞く
2. **「訳」ボタンで意味確認** — 1回だけ確認しまた英語で聞く
3. **3択で答える** — 自分のターンで正解を選ぶ
4. **同じ会話を3回繰り返す** — 1回目=理解、2回目=予測、3回目=反射
5. **3星(100%)を目指してマスター** — 次のシュチュエーションへ
6. **シャドーイング** — 🐢Slow → Normal速度で口に染み込ませる

1日10〜15分、3シュチュエーションが目安。3ヶ月でLv100到達設計。

## 🛠 トラブルシューティング

### 音声が出ない
- **iOS Safari は最初の画面タップまで音声が鳴らない仕様** です
- ホームを開いたあと、必ず一度どこかをタップしてください
- それでも鳴らない場合: 端末の音量・サイレントモードを確認

### 🎙️ もっと自然な音声にする方法 (無料・iPhone)
標準音声はやや機械的なので、**Enhanced/Premium 音声を入れると劇的に自然**になります。

1. iPhone の **設定** アプリを開く
2. **アクセシビリティ** → **読み上げコンテンツ** → **声**
3. **英語 (English)** をタップ
4. 一覧から **「拡張」または「プレミアム」** と書かれた音声を選んでダウンロード
   - おすすめ: **Ava (Enhanced)** / **Tom (Enhanced)** / **Allison (Enhanced)**
   - サイズ: 60〜200MB (Wi-Fi推奨)
5. アプリに戻り、チャット画面右上の **🎙️ ボタン** から好きな声を選択
6. 一度選べば次回以降も同じ声で再生されます

これだけで、ロボット感のないかなり自然な英語音声に変わります。

### 画面が古いまま更新されない
ブラウザキャッシュを削除して再アクセスしてください:
- iPhone Safari: 設定 → Safari → 履歴とWebサイトデータを消去
- Chrome: シークレットウィンドウで開き直す

### リンクが効かない / 真っ白
- 全ファイル (index.html / pattern-c.html / data.js) がリポジトリに揃っているか確認
- ブラウザのコンソール (F12) でエラーを確認

## 📁 ファイル構成

```
english-app/
├── index.html      # ホーム画面 (レベル/ステージ/おすすめ)
├── pattern-c.html  # チャット会話画面
├── data.js         # 全25会話データ + カリキュラム計算 + TTS音声
└── README.md
```

3ファイルだけのシンプル構成。`data.js` を編集すればシュチュエーションを追加・変更できます。

## 🤖 技術

- HTML / CSS / JavaScript のみ (フレームワーク不使用)
- Web Speech API (TTS) でブラウザ標準音声を使用
- localStorage で進捗保存
- バックエンド・サーバー不要の完全静的サイト
